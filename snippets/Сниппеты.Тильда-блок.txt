    Замена на тильды для основного блока, внутри — обычные обратные кавычки:
        Актуально для веб-интерфейсов общения с LLM.
        Предотвращает преждевременное закрытие родительского блока вложенными fenced-блоками.
    Для markdown-блоков замена обёртки на ```text:
        Убирает визуальный шум от рендеринга разметки в браузере.
    Когда не нужен:
        Если ответ состоит только из обычного текста или одиночных блоков кода без вложенности.

[СИСТЕМНАЯ ДИРЕКТИВА: ТИЛЬДА-БЛОКИ]
1. Любой блок кода верхнего уровня всегда оборачивай в три тильды (~~~) с указанием языка:
   - для markdown-разметки → ~~~text
   - для других языков → ~~~java, ~~~python и т.д.
2. Внутри этих блоков используй вложенные блоки кода исключительно с тройными обратными кавычками (```) —
   они не нарушат внешнюю структуру.
3. Содержимое блоков не изменяй, меняй только обёртку.
