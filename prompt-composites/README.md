# Composite Prompts (Сборки)

Готовые к использованию сборки: промты, составленные из нескольких модулей
репозитория — роли и add-on (Behavior, Format, Skill). Позволяют запустить
сложную конфигурацию «в один клик», без ручной сборки в диалоге.

Правила сборки — в [composite-assembly.md](../guidelines/composite-assembly.md).
Типы модулей — в [entity-taxonomy.md](../guidelines/entity-taxonomy.md).


============================================================
## Что такое Composite

Composite — это промт, в котором последовательно соединены несколько модулей:

- **одна Role** — задаёт идентичность и стойку;
- **add-on** (Behavior, Format, Skill) — расширяют поведение, оформление или
  знания;
- **ровно одна стойка** — вторая стойка в композите запрещена. Нужны две —
  это не Composite, а другая роль.

Примеры файлов в этой папке:

- `Медик.Критик.txt`
- `Психолог.Критик.КритикПсихологии.txt`
- `Психолог.Критик.КритикПсихологии.Коллега.txt`
- `LLM-эксперт.Ролевик.Критик.txt`

Имя файла отражает состав сборки: модули перечислены через точку в порядке
подключения. Role — всегда первая, остальные — по логике сборки.


============================================================
## Как собрать свою сборку

1. Возьмите Role из `prompts/roles/` или `prompt-by-theme/<тема>/` — она
   содержит «Ты — …» и задаёт стойку.
2. Добавьте нужные add-on **последовательно**, начиная каждый с его
   Behavior-версии («Мыслишь как …» или список компетенций без «Ты — …»).
3. Убедитесь, что нигде, кроме Role, нет конструкции «Ты — …».
4. Сохраните файл с именем, отражающим состав: `Role.Addon.Addon.txt`.
5. В шапке проставьте версии:

```
// composite: <имя> @ <версия>
// встроено: <имя>.<тип> @ <версия>, <имя>.<тип> @ <версия>
```

Версия Composite = самая поздняя из версий встроенных add-on.

**Важно.** Обёртка `Плагин-дополнительных-инструкций.txt` здесь **не нужна**.
Она — для динамического добавления в идущем диалоге. В статической сборке все
инструкции задаются одновременно и воспринимаются моделью как единое целое.

**Пример** сборки «Психолог + Критик + Коллега»:

- Взять `Психолог-аналитик.ROLE.txt` из `prompt-by-theme/psychology/`.
- Сразу за ним вставить содержимое `Критик-аналитик.BEHAVIOR.txt`.
- Затем — `Коллега.BEHAVIOR.txt`.
- Убедиться, что только Психолог начинается с «Ты — …».
- Сохранить как `Психолог.Критик.Коллега.txt`.
- В шапку — версии: composite + встроенные add-on.


============================================================
## Важные предостережения

**Не редактируйте файлы в этой папке вручную.** Если нужно изменить поведение
сборки — правьте исходные модули в их директориях (`prompts/`,
`prompt-by-theme/`) и пересобирайте композит.

**Версии модулей могут отставать.** Композит собран из версий, актуальных на
момент сборки. Если позже исходный модуль обновился — композит всё ещё содержит
предыдущую версию. Это не делает его нерабочим, но для максимальной точности
сверяйтесь с версиями в шапке и при необходимости пересобирайте.

**Имена файлов — это схема сборки.** `Психолог.Критик.Коллега.txt` означает:
Role — Психолог, к ней подключены Критик и Коллега, именно в таком порядке.


============================================================
## Для AI-агентов

- Считать содержимое файла цельным, готовым к использованию промтом.
- **Не модифицировать**: не добавлять и не убирать модули.
- Если нужна новая сборка — брать исходные модули из `prompts/` и
  `prompt-by-theme/`, следовать инструкции из §«Как собрать свою сборку».
