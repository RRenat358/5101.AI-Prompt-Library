# 5101.AI-Prompt-Library

Личный репозиторий промптов для ИИ.  
Создаю сам и для себя.  

Почти всё выращено из собственной практики и в ходе обучения LLM инженерии.  
Иногда, очень редко, использую наработки других промт-инженеров (частично или целиком).  

Буду рад, если кому-то пригодится эта небольшая база).  

============================================================  
## Что внутри

- `prompts/` -- готовые промпты, разбитые по темам
- `composite-prompts/` -- промт-сборки из промтов нескольких модулей репозитория (ролей, режимов, сниппетов, плагинов).
- `snippets/` -- переиспользуемые фрагменты и приёмы
- `guidelines/` -- мои правила оформления, система разделителей и заголовков
- `examples/` -- наглядные примеры структуры промптов
- `AGENTS.md` -- инструкция для AI-ассистентов (и людей) по работе с репозиторием


## Основные темы

- Психология и психотерапия
- Медицина
- Обработка и анализ текста
- Поиск и фактчекинг
- Разработка и code review
- LLM: Системные инструкции и управление контекстом
- Промт-инженеринг


## Быстрый старт

Просто открой нужную папку, выбери промпт и скопируй в чат с LLM.  
Все файлы — обычный текст (`.txt`), читаются без специальных инструментов.


## Хочешь помочь или предложить улучшение?

там описаны стандарты оформления.
