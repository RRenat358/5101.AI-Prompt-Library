# Система визуальных разделителей

Настоящий документ определяет правила применения визуальных разделителей
в промптах, сниппетах и сопроводительных файлах репозитория.
Разделители помогают человеку быстро ориентироваться в структуре,
а LLM — чётче разграничивать смысловые блоки.

## 1. Базовые принципы

1. **Вес символа** — чем "тяжелее" символ, тем выше уровень разделения:
   `━━━` > `===` > `---` (используется особым образом).

2. **Длина строки** — чем короче линия, тем меньше её разделительная сила.
   Принята строгая градация длин: **60, 40, 20, 10, 5, 3** символов.

3. **Единообразие** — внутри одного промпта используйте не более 3-4 типов
   разделителей, соблюдая их иерархию.

4. **Не перегружайте** — избыток линий размывает внимание.
   Разделитель ставится только перед началом логического блока.

## 2. Стандартные разделители и их назначение

| Символ  | Длина | Уровень          | Когда использовать |
|:--------|:------|:-----------------| :--- |
| `━━━`   | 60    | **Максимальный** | Обрамление мета-блока. Самая важная граница — между метой и телом промпта. |
| `=====` | 40    | **Высокий**      | Разделение крупных частей внутри тела: Роль, Контекст, Правила, Формат ответа. |
| `-----` | 20    | **Средний**      | Разделение подсекций внутри одной крупной части (например, разные группы правил). |
| `=====` | 10    | **Умеренный**    | Разделение мелких подразделов или важных акцентов внутри секции. |
| `-----` | 5     | **Низкий**       | Отбивка небольших уточнений, примеров, примечаний. |
| `---`   | 3     | **Особый**       | **Только** для отделения мета-блока (если не используется `━━━`), финального вывода, дополнительных системных установок, которые не входят в тело промпта. Никогда не применяется внутри блоков. |

## 3. Особый случай `---` (3 символа)

Строка из трёх дефисов `---` — стандартный разделитель Markdown (горизонтальная линия).
В нашем проекте он **зарезервирован** для трёх ситуаций:

- отделение мета-блока от тела промпта (если не используется `━━━`);
- выделение финального ответа или резюме в конце промпта;
- отделение дополнительных системных инструкций, которые не входят в основной промпт.

Никогда не вставляйте `---` как рядовой разделитель внутри блоков — для этого есть линии 5, 10 или 20 символов.
