# Система тегов

Теги используются в мета-блоке каждого промт-артефакта для классификации,
поиска и фильтрации. Все теги начинаются с `#` и записываются в нижнем
регистре. Формат записи в мета-блоке — [meta-block.md](meta-block.md), §3.

Три группы обязательны: **тип**, **тема/область**, **статус**. После третьей
можно добавлять другие группы — список не закрыт.


============================================================
## 1. Тип

Что это за файл по своей сути. Может быть несколько тегов в группе:
`#composite, #role` — композит, внутри которого роль.

- `#action` — задача/операция: «создай снимок», «сегментируй диалог».
- `#behavior` — предписание поведения/тона: «мысли как скептик», «будь коллегой».
- `#composite` — сборка из нескольких модулей. Всегда первый тег у Composite.
- `#format` — правила оформления вывода: тильда-блоки, структура, разбиение.
- `#guide` — sidecar-документация рядом с промтом (`.GUIDE.txt`).
- `#role` — идентичность: «Ты — …» + база + стойка.
- `#skill` — знание: техники, чек-листы, подводные камни. Stance-neutral.
- `#snippet` — набор нано-инструкций (`.SNIPPETS.txt`).
- `#wrapper` — контейнер для добавления add-on в идущем диалоге.


============================================================
## 2. Тема / область

К какой предметной области относится. Соответствует темам в
`prompt-by-theme/`. Может быть несколько тегов в группе.

- `#education` — обучение, коучинг, решатели тестов.
- `#it` — IT: тестирование, разработка, DevOps, инфраструктура, безопасность.
- `#llm` — LLM: промт-инжиниринг, агенты, работа с моделями.
- `#psychology` — психология, терапия, работа с данными.
- `#spirituality` — духовные вопросы, теология.
- `#writing` — работа с текстом: генерация, обработка, анализ.

Список открыт: новая тема добавляется сюда перед первым использованием.


============================================================
## 3. Статус

Готовность файла к использованию. Один тег на файл.

- `#archived` — устарел, сохранён для истории.
- `#draft` — черновик, требуется доработка.
- `#ready` — готов и рекомендован к использованию.
- `#test` — недостаточно проверен на практике, возможен критический анализ.


============================================================
## 4. Дополнительные (опционально)

Любые уточняющие теги после третьей группы. Список открыт.

Примеры:
- `#context` — управление контекстом.
- `#critic` — критическое мышление.
- `#jailbreak` — техники обхода ограничений (если применимо).
- `#memory` — работа с памятью диалога.
- `#system` — системный промт, определяющий поведение LLM.
- `#target-gpt-4o` — под конкретную модель.


============================================================
## Правила использования

- **Три группы обязательны:** тип, тема/область, статус.
- **Внутри группы** — через запятую: `#composite, #role,`.
- **Между группами** — таб (4 пробела): `#composite, #role,    #psychology,    #ready`.
  Таб — для человека, чтобы группы читались визуально. Парсер работает и без
  него, но с запятыми — обязательно.
- **В группе** — любое количество тегов. Не ограничивайте себя одним-двумя.
- **После третьей группы** можно добавлять другие группы — список не закрыт.
- **Поиск по тегу** находит все файлы, где он есть. `#role` найдёт и роли, и
  композиты с ролями — это фича, а не баг.
- **Новые теги** добавляются в этот файл перед первым использованием.


============================================================
## Примеры

```
tags: #action,    #writing,    #draft
tags: #behavior,    #psychology,    #ready
tags: #role,    #it,    #ready
tags: #skill,    #it,    #test
tags: #snippet,    #llm,    #test
tags: #format,    #it,    #ready
tags: #composite, #role,    #psychology,    #ready
tags: #composite, #role,    #it,    #ready,    #target-gpt-4o
```


============================================================
## Расширение системы

Новая тема или дополнительный тег — сначала в этот файл, потом в файлы.
Стиль: нижний регистр, осмысленное английское слово или короткое
словосочетание через дефис (`#target-gpt-4o`).
