# Composite Prompts (Сборки)

В этой директории лежат готовые к использованию сборки — 
промты, составленные из нескольких модулей репозитория (ролей, режимов, сниппетов, плагинов).
Они позволяют запустить сложную конфигурацию «в один клик», без ручной сборки в диалоге.


============================================================
## Что такое сборка

Сборка — это промт, в котором последовательно соединены несколько модулей. Обычно это:
- одна основная роль (например, `Психолог-аналитик`),
- один или несколько режимов или плагинов (`Критик-аналитик`, `Коллега`),
- при необходимости — специфические сниппеты (`Критический-анализ-в-психологии`).

Примеры файлов в этой папке:
- `Медик.Критик.txt`
- `Психолог.Критик.КритПсихология.Коллега.txt`
- `Сисадмин.Критик.txt`

Имя файла отражает состав сборки: модули перечислены через точку в порядке их подключения.


============================================================
## Как собрать свою сборку

Вы можете создать собственную сборку, если стандартной вам недостаточно. Для этого:

1. Возьмите основную роль из `roles/`.
2. Если нужен режим (например, `Коллега`) — добавьте его через `Плагин-дополнительных-инструкций.txt`.
3. Если нужны дополнительные компетенции (например, `Критик-аналитик` или `Критический-анализ-в-психологии`) — так же добавьте их через плагин.
4. Соедините всё в одном текстовом файле в правильном порядке.

Порядок важен: сначала основная роль, затем универсальные надстройки, затем специфические.

Пример сборки «Психолог + Критик + Коллега»:

1. Взять `Психолог-аналитик.txt` из `roles/psychology/`.
2. Взять `Плагин-дополнительных-инструкций.txt` из `plugins/`.
3. В секцию `**Дополнительные инструкции:**` вставить:
    - Сначала `Критик-аналитик.Плагин.txt` из `roles/`.
    - Затем `Коллега.Плагин.txt` из `modes/`.
4. Сохранить результат как `Психолог.Критик.Коллега.txt` в `composite-prompts/`.


============================================================
## Важные предостережения

**Не редактируйте файлы в этой папке.** 
Если вы хотите изменить поведение сборки, меняйте исходные модули в их директориях (`roles/`, `modes/`, `snippets/`) 
и затем пересобирайте сборку заново.

**Версии модулей могут немного отставать.** 
Сборки создаются из последних стабильных версий на момент их составления. 
Если позже исходный модуль был обновлён, сборка всё ещё содержит его предыдущую версию. 
Это не делает промт нерабочим — он по-прежнему выполняет свою задачу. 
Но для максимальной точности сверяйтесь с датами версий в мета-данных модулей.

**Имена файлов — это схема сборки.** 
Если вы видите `Психолог.Критик.Коллега.txt`, это значит: базовая роль — Психолог, 
к ней подключены Критик и Коллега (именно в таком порядке).


============================================================
## Для AI-агентов

При чтении файлов из этой директории агент должен:
- Считать содержимое файла цельным, готовым к использованию промтом.
- **Не модифицировать** его, не добавлять и не убирать модули — файл уже является законченной инструкцией.
- Если агент хочет составить новую сборку, он должен брать исходные модули из `roles/`, `modes/`, `snippets/` и следовать инструкции в разделе «Как собрать свою сборку».
