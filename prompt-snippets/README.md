# Общие сниппеты (prompt-snippets)

Наборы нано-инструкций: 1–2 предложения каждая, сгруппированные по теме.
Не сущность, а контейнер — как Wrapper, но для мелких инструкций.

Snippets — это не «маленький Skill». Это другой формат: Skill — полноценный
пакет знания, Snippets — сборник коротких заготовок, которые берут построчно.


============================================================
## Зачем

Дробить 20 нано-инструкций на 20 файлов — хуже, чем один сборник. Много
файлов с нано-содержимым трудно просматривать, а нужную инструкцию
приходится искать перебором.

Сборник решает: все короткие заготовки по теме — на одном экране, бери
нужную и вставляй. Как сниппеты в редакторе кода: не файл целиком, а строка.


============================================================
## Как устроено

**Имя:** `<тема>.SNIPPETS.txt`. Например, `LLM.SNIPPETS.txt`,
`Общие.SNIPPETS.txt`.

**Привязка к сущности.** Если сборник тематически про одну сущность —
лежит в папке этой сущности:

- `prompts/behaviors/<имя>.SNIPPETS.txt` — нано-инструкции про поведение;
- `prompts/formats/<имя>.SNIPPETS.txt` — нано-инструкции про оформление.

Если сборник общий, вне одной сущности — здесь, в `prompt-snippets/`.

**Внутри** — маркированные мини-инструкции, каждая самодостаточна. Не
зависят друг от друга: можно взять любую, не таща остальные.

**Не участвует в сборке композитов автоматически.** Snippets копируются
построчно вручную или через Wrapper. Это не блок композита.


============================================================
## Как использовать

1. Открой нужный `.SNIPPETS.txt`.
2. Найди мини-инструкцию по теме.
3. Скопируй **строку** (или несколько), не файл целиком.
4. Вставь в диалог — как есть или через
   [Плагин-дополнительных-инструкций.txt](../prompt-wrappers/Плагин-дополнительных-инструкций.txt).

Если инструкция нужна постоянно — возможно, это уже не Snippets, а Skill
или Behavior. См. «Как отличить».


============================================================
## Как отличить от соседей

**От Skill.** Skill — полноценный пакет знания (5–20 строк: техники,
чек-листы, подводные камни). Snippets — нано-инструкции (1–2 предложения
каждая), сборник. Если знание не дотягивает до полноценного пакета — это
Snippets, не Skill.

**От Behavior.** Behavior — предписание поведения, которое подключается
к роли. Snippets — набор мелких инструкций, каждая сама по себе. Behavior
меняет, как модель себя ведёт; Snippets добавляют точечные правила.

**От Format.** Format — правила оформления вывода. Snippets — любые
нано-инструкции, не обязательно про оформление.

**Тест:** если убрать одну строку из Snippets — ничего не сломается,
остальные работают. Если убрать Skill — ответ станет заметно беднее.
Snippets — россыпь, Skill — пакет.


============================================================
## Пример

`LLM.SNIPPETS.txt`:

```
# LLM — нано-инструкции

- Если пользователь просит «объясни проще» — используй аналогии из быта,
  не из программирования.
- Не начинай ответ с «Конечно!» или «Отличный вопрос!».
- Если не уверен в факте — помечай «предположение», не выдавай за факт.
- Для длинных ответов — сначала одна строка-итог, потом детали.
```

Здесь:
- **четыре независимые инструкции** — можно взять любую;
- **каждая — 1–2 предложения** — не пакет знания, а точечное правило;
- **сборник** — все про LLM, лежат вместе, чтобы не искать по 20 файлам.
