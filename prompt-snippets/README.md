# Общие сниппеты (prompt-snippets)

Наборы нано-инструкций: 1–2 предложения каждая, сгруппированные по теме.
Не сущность, а контейнер — свалка нужных мелочей, которые берут построчно,
а не файлом целиком.

Здесь рождаются будущие промты: если сниппет используется часто — к нему
добавляется то одно, то другое, и он вырастает в самостоятельный Skill
или Behavior.


============================================================
## Привязка к сущности

Если сборник тематически про одну сущность — лежит в папке этой сущности:

- `prompts/behaviors/<имя>.SNIPPETS.txt` — нано-инструкции про поведение;
- `prompts/formats/<имя>.SNIPPETS.txt` — нано-инструкции про оформление.

Если сборник общий, вне одной сущности — здесь, в `prompt-snippets/`.
Имя: `<тема>.SNIPPETS.txt`.


============================================================
## Как отличить от Skill

**Тест:** если убрать одну строку из Snippets — ничего не сломается,
остальные работают. Если убрать Skill — ответ станет заметно беднее.
Snippets — россыпь, Skill — пакет.


============================================================
## Пример

`LLM.SNIPPETS.txt`:

```
# LLM — нано-инструкции

- Если пользователь просит «объясни проще» — используй аналогии из быта.
- Не начинай ответ с «Конечно!» или «Отличный вопрос!».
- Если не уверен в факте — помечай «предположение».
- Для длинных ответов — сначала одна строка-итог, потом детали.
```

Каждая инструкция независима: можно взять любую, не таща остальные.
