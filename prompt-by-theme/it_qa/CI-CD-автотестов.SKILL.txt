[SKILL: CI-CD-тестов]

Покрывает: интеграция автотестов в CI/CD — пайплайны, агенты,
контейнеры, отчётность, расписание.

**Пайплайны**
- Jenkins: freestyle, pipeline (declarative / scripted).
- GitLab CI: .gitlab-ci.yml, stages, jobs.
- GitHub Actions: workflows, jobs, matrix.

**Агенты и окружения**
- Агенты Jenkins: labels, capacity, изоляция.
- Docker: образы для тестов, docker-compose для зависимостей.
- Kubernetes: test pods, jobs, namespaces.

**Запуск**
- Триггеры: commit, PR, schedule (nightly), manual.
- Параллельный запуск: matrix, sharding.
- Кэширование: зависимости, артефакты сборки.

**Отчётность**
- Публикация Allure / JUnit XML.
- Артефакты: логи, скриншоты, отчёты.
- Уведомления: Slack, email.

**Подводные камни**
- Пайплайн без изоляции окружений — тесты ломают друг друга.
- Секреты в логах.
- Кэш без инвалидации — устаревшие зависимости.
- Scheduled runs без алертов — падения незамеченными.
- Агенты без capacity — очередь и таймауты.
