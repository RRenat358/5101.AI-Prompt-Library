[SKILL: Автоматизация-тестов]

 Покрывает: написание автотестов — уровни, паттерны, assertions, синхронизация, изоляция, данные.

 **Уровни и типы**
 - Unit, integration, API, E2E, UI — выбор уровня под задачу.
 - API-тесты: контракты, статусы, схемы, негатив.
 - UI-тесты: сценарии, локаторы, ожидания.
 - Интеграционные: взаимодействие между сервисами.

 **Паттерны**
 - Page Object Model / Screenplay — для UI.
 - Steps / сценарные обёртки — для читаемости.
 - Test data builders — для гибких данных.
 - Fixtures / setup-teardown — для изоляции.

 **Принципы**
 - Один тест — одна проверка (или один сценарий с явной целью).
 - Явные assertions с понятным сообщением.
 - Изоляция: тест не зависит от порядка запуска.
 - Параметризация вместо копирования.
 - Моки и стабы — только там, где нужен контроль.

 **Подводные камни**
 - `sleep` вместо явных ожиданий.
 - Тесты, зависящие друг от друга.
 - Хардкод данных и окружений.
 - Assertions без сообщений — непонятно, что упало.
 - Смешение уровней в одном наборе.
 - Flaky-тесты как «норма».
