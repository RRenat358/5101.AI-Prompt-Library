[GUIDE: ИТ-соглашения]

Соглашения для ИТ-Ролей, Skills и Композитов. Частные правила домена,
не выводятся из общих модулей таксономии и форм-факторов.

**Два слоя Skills**
- Универсальный Skill — инварианты, решения, анти-паттерны. Без имён инструментов и фреймворков. Шарится между всеми Ролями домена.
- Инструментальный Skill — один инструмент, один файл. Глубина по конкретному инструменту: API, паттерны, подводные камни.

**Загрузка в композит**
- Универсальные Skills подключаются всегда, когда Роль этого домена активна.
- Инструментальные Skills подключаются по текущему стеку проекта.
- Если инструментальный Skill не подключён — модель выберет инструмент сама,
  возможно не тот. Дисциплина сборки: под текущий стек — свой инструментальный Skill.

**Именование**
- Универсальный Skill: `<область>.SKILL.txt` — например, `Автоматизация-тестов.SKILL.txt`.
- Инструментальный Skill: `<Инструмент>.SKILL.txt` — например, `JUnit5.SKILL.txt`, `Playwright.SKILL.txt`, `Jenkins.SKILL.txt`.
- Имя инструмента — как в индустрии, без перевода и транслитерации.

**Что не попадает в универсальный Skill**
- Имена фреймворков, библиотек, CI-систем, БД.
- Синтаксис и API инструментов.
- Версии инструментов.

**Возрастная устойчивость инструментального Skill**
- Включай: архитектурные концепции, классы проблем, best practices с обоснованием.
- Не включай: конкретные версии, транзиентные баги, workarounds для
  конкретных версий, точные имена методов, которые могут переименовать.
- Тест: «если это исправят в следующей версии — пункт устареет?» Если да — не включать.
- Тест: «это структурное свойство инструмента или временное?» Структурное — включать с объяснением; временное — нет.
- Обоснование важнее практики: «почему» переживает версии, «как» — нет.

**Термины: delta и self-contained**
- **Delta** — инструментальный Skill содержит только то, что отличает инструмент от универсального Skill и от других инструментов
  (если один — обёртка над другим). Не повторяет общее.
- **Self-contained** — инструментальный Skill можно загрузить в одиночку и использовать, не загружая другие инструментальные Skills.
  Может ссылаться на другие, но не требует их загрузки.
- Совместимы: self-contained про использование, delta про содержание.
