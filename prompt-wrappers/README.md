# Обёртки (prompt-wrappers)

Контейнеры для динамического добавления add-on в **идущий** диалог. Обёртка
оборачивает Behavior, Format, Skill или Snippets так, чтобы модель восприняла
их как настройку, а не как обычное сообщение пользователя.

Wrapper — не сущность. Он не добавляет ничего от себя: только рамку, внутри
которой add-on работает.


============================================================
## Зачем

В идущем диалоге роль уже задана. Если просто отправить «Мысли как скептик» —
модель может воспринять это как реплику, а не как изменение поведения.
Обёртка говорит явно: «это не реплика, это дополнение к твоим настройкам».

Без обёртки add-on работает хуже: модель может проигнорировать, понять
буквально или применить к одному ответу. С обёрткой — воспринимает как
часть роли.


============================================================
## Как устроено

Обёртка — это шаблон с якорной фразой:

```
[ПЛАГИН ДОПОЛНИТЕЛЬНЫХ ИНСТРУКЦИЙ]

Всё, что было задано ранее (роль, настройки, режимы, инструкции и прочее),
остаётся неизменным и сохраняет силу.
Ты не меняешь свою личность и не отменяешь действующие правила.

"Дополнительные инструкции" (нижеследующий текст) -- дополняют твоё текущее
поведение, а не заменяют его.
Примени их вместе с уже действующими.

Если дополнительная инструкция противоречит ранее заданной — приоритет у
дополнительной.

**Дополнительные инструкции:**
// сюда вставляется содержимое Behavior/Format/Skill/Snippets
```

Якорная фраза «сохраняя текущую роль и предыдущие настройки» — ключевая:
она говорит модели не сбрасывать то, что уже задано.


============================================================
## Как использовать

1. Роль уже задана в диалоге.
2. Возьмите нужный add-on (Behavior, Format, Skill, Snippets).
3. Вставьте его содержимое **внутрь** обёртки.
4. Отправьте сообщением.

Несколько add-on — вставляйте последовательно в одну обёртку или несколькими
сообщениями, сохраняя якорную фразу.

**Для статической сборки обёртка не нужна.** Composite — это файл, где все
блоки заданы одновременно. Обёртка — только для идущего диалога. Подробнее —
[dynamic-additions.md](../guidelines/dynamic-additions.md).


============================================================
## Как отличить от Composite

**Composite** — статическая сборка: файл, все блоки сразу. Используется
в начале диалога.

**Wrapper** — динамическое добавление: обёртка, в середине диалога. Роль
уже задана, add-on добавляется поверх.

Если собираете файл — это Composite. Если добавляете в идущий диалог —
Wrapper.


============================================================
## Пример

В диалоге уже работает Психолог. Нужно добавить Критика:

```
[ПЛАГИН ДОПОЛНИТЕЛЬНЫХ ИНСТРУКЦИЙ]

Всё, что было задано ранее, остаётся неизменным и сохраняет силу.
Ты не меняешь свою личность и не отменяешь действующие правила.

"Дополнительные инструкции" -- дополняют твоё текущее поведение, а не
заменяют его. Примени их вместе с уже действующими.

Если дополнительная инструкция противоречит ранее заданной — приоритет у
дополнительной.

**Дополнительные инструкции:**

[BEHAVIOR: Критик-аналитик]
Мыслишь как беспристрастный аналитик-скептик.
Сначала усомнись, потом согласись.
...
```

Психолог остаётся Психологом, но теперь с критической рамкой.
