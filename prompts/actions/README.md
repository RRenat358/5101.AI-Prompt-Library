# Задача (Action)

Операция: «создай снимок», «сегментируй диалог», «гуманизируй текст».
Задаёт, **что сделать** — без идентичности как первичной природы.

Action — это операция, а не персона. Он может содержать встроенные элементы
других типов (тон, техники, структуру вывода), но первичная природа — задача.


============================================================
## На какие вопросы отвечает

- «Что сделать?» — операция: создать, проанализировать, переписать, сегментировать.
- «Какую задачу выполнить?» — конкретное действие: снимок диалога, гуманизация текста.
- «По какому алгоритму?» — шаги, структура, чек-лист выполнения.

- **Операция** — что именно сделать.
- **Алгоритм** — как выполнять: шаги, структура, критерии готовности.
- **Встроенные элементы** — Action может содержать тон (Behavior-элемент),
  техники (Skill-элемент), структуру вывода (Format-элемент). Это нормально:
  операция первична, остальное — вспомогательное.


============================================================
## Как отличить от соседей

**От Role.** Role отвечает «кто ты», Action — «что сделай». Подробнее — ниже,
в спорном случае.

**От Behavior.** Behavior — манера или тон. Action — конкретная операция.
«Мысли как скептик» — Behavior. «Создай снимок диалога» — Action.

**От Skill.** Skill — знание. Action — выполнение. Skill говорит «что
учитывать», Action — «что сделать».

**От Composite.** Composite — сборка Role + add-on. Action — самостоятельная
операция. Если Action содержит встроенные элементы других типов — это всё
равно Action, не Composite: первичная природа — операция.

Детали и спорные случаи — [entity-taxonomy.md](../../guidelines/entity-taxonomy.md).


============================================================
## Спорный случай: Action с «Ты — …»

Action может содержать «Ты — …», и это сбивает. Как отличить от Role?

**Смотрите на функцию, а не на форму.** В Action «Ты — …» — это угол
выполнения задачи, а не суть файла. Уберите «Ты — …» из Action — задача
останется понятной. Уберите из Role — останутся компетенции без владельца.

- **Action:** «Ты — эксперт по извлечению данных. Создай снимок диалога.»
  Уберите «Ты — эксперт» — останется «Создай снимок». Задача ясна.
- **Role:** «Ты — ветеринар. [компетенции]» Уберите «Ты — ветеринар» —
  останется список компетенций. Непонятно, чей он.

**Тест:** уберите «Ты — …» из файла. Задача осталась понятной → Action.
Смысл потерян → Role.


============================================================
## Роль в Action: явная и неявная

Как стойка в Role может быть неявной (LLM подтянет из дефолта по
идентичности), так и Role в Action может быть неявной. Задавая операцию, вы
не обязаны писать «Ты — …»: модель сама подтянет подходящую роль из контекста.

- **Неявная роль:** «Создай снимок диалога со структурой…» — LLM поймёт, что
  нужна аналитическая роль. В большинстве случаев этого достаточно.
- **Явная роль:** «Мыслишь как редактор, специализирующийся на гуманизации.
  Перепиши текст…» — когда нужен специфический угол, который LLM не выберет
  сам, или когда операция неоднозначна.

Явная роль нужна в трёх случаях: операция неоднозначна, нужен специфический
угол, нужна фиксация для стабильности. В остальном — не мешайте дефолту
модели: она подберёт сбалансированную роль по контексту.


============================================================
## Как идентифицировать

**Тест:** уберите Action — модель не выполнит операцию (не создаст снимок,
не сегментирует диалог). Если да — это Action.

Если после удаления файла модель всё равно выполнит задачу (просто менее
глубоко) — это Skill. Если изменится только тон — Behavior. Если пропадёт
идентичность — Role.

**Маркер:** начинается с `[ACTION: …]` или с формулировки задачи: «Задача:»,
«Создай», «Проанализируй», «Выполни». Может содержать «Ты — …» как встроенный
элемент — см. спорный случай выше.


============================================================
## Как создать

1. **Сформулируйте операцию** — что именно сделать. Одно предложение, глагол
   действия: «создай», «проанализируй», «перепиши», «сегментируй».
2. **Опишите алгоритм** — шаги, структура, критерии готовности. Если операция
   сложная — разбейте на блоки.
3. **Роль** — только если нужно переопределить дефолт (неоднозначная операция,
   специфический угол, фиксация). В большинстве случаев достаточно операции:
   LLM подтянет роль по контексту.
4. **Добавьте вспомогательное** — если нужен тон (Behavior-элемент), техники
   (Skill-элемент) или структура вывода (Format-элемент). Не перегружайте:
   Action — про операцию, не про всё сразу.
5. **Имя файла** — в `actions/` без суффикса (дефолт папки). В плоском
   каталоге или чужой папке — `.ACTION.txt`. Правила —
   [entity-taxonomy.md](../../guidelines/entity-taxonomy.md), §7.
6. **Мета-блок** — [meta-block.md](../../guidelines/meta-block.md).

## Пример 1. Контекстный снимок (неявная роль)

```
[ACTION: Контекстный-снимок]
Задача: проанализируй все предыдущие сообщения в диалоге и создай
структурированную сводку для продолжения в новом чате.

[СТРУКТУРА]
- Ключевые темы и решения.
- Открытые вопросы.
- Договорённости и ограничения.
- Что осталось незавершённым.
```

Здесь:
- **операция** — «создай сводку»;
- **алгоритм** — структура из четырёх блоков;
- **встроенный Format-элемент** — структура вывода;
- **роль — неявная**: «Ты — …» не прописана. LLM подтянет аналитическую роль
  из контекста операции. Для снимка диалога этого достаточно — не мешаем
  дефолту модели.


============================================================
## Пример 2. Гуманизация текста (явная роль)

```
[ACTION: Гуманизация текста]
Мыслишь как редактор, специализирующийся на гуманизации.
Задача: перепиши предоставленный текст так, чтобы он звучал как написанный
живым человеком. Сними явные маркеры ИИ, сохраняя стиль и голос оригинала.

[ЧЕК-ЛИСТ]
- Убрать канцелярит и штампы.
- Разнообразить длину предложений.
- Заменить шаблонные связки на живые.
- Сохранить смысл и ключевые термины.
```

Здесь:
- **операция** — «перепиши текст»;
- **роль — явная**: «Мыслишь как редактор, специализирующийся на гуманизации».
  Нужен специфический угол — не просто «переписать», а именно гуманизировать,
  снять маркеры ИИ. Дефолтная роль могла бы уйти в сторону (например, просто
  «улучшить стиль»), поэтому фиксируем явно;
- **встроенный Skill-элемент** — чек-лист маркеров;
- **первичная природа** — Action: без операции это был бы Behavior или Skill,
  но здесь они вспомогательные.
