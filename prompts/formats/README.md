# Формат (Format)

Правила оформления вывода: структура, разметка, обёртки, разбиение.
Задаёт, **как оформить ответ** — без изменения содержания, тона или поведения.

Format — это presentation, а не content. Он не говорит «что сказать» и не
говорит «как себя вести». Он говорит «в каком виде подать».


============================================================
## На какие вопросы отвечает

- «Как оформить ответ?» — структура, разметка.
- «В каком виде подать?» — обёртки, блоки, разделители.
- «Как разбить?» — на части, секции, шаги.

- **Структура** — как организован ответ: секции, блоки, порядок.
- **Разметка** — техническое оформление: тильда-блоки, таблицы, списки.
- **Обёртка** — что добавить к ответу: таймстамп, разделитель, метку.


============================================================
## Как отличить от соседей

**От Behavior.** Behavior меняет тон или диспозицию. Format — только
оформление. «Мысли как скептик» — Behavior. «Оборачивай код в тильда-блоки» —
Format.

**От Skill.** Skill даёт знание. Format — оформление. Skill говорит «что
учитывать», Format — «как подать».

**От Action.** Action — операция («что сделай»). Format — оформление
результата. Action создаёт снимок, Format говорит, как его структурировать.

Детали и спорные случаи — [entity-taxonomy.md](../../guidelines/entity-taxonomy.md).


============================================================
## Как идентифицировать

**Тест:** уберите Format — содержание ответа не изменится, изменится только
оформление. Если да — это Format.

Если после удаления файла меняется смысл или тон — это не Format, а Behavior
или Skill.

**Маркер:** содержит правила оформления: «оборачивай в …», «разбивай на …»,
«добавляй …», «используй …». Не содержит «Ты — …» и не содержит техник/знаний.


============================================================
## Как создать

1. **Сформулируйте правило оформления** — что и как оформить. Конкретно:
   «оборачивай код в тильда-блоки с указанием языка», «добавляй таймстамп
   в начало каждого сообщения».
2. **Проверьте на content-neutral** — уберите Format мысленно: содержание
   ответа то же? Если да — оформление. Если меняется смысл — это Behavior
   или Skill.
3. **Имя файла** — в `formats/` без суффикса (дефолт папки). В плоском
   каталоге или чужой папке — `.FORMAT.txt`. Правила —
   [entity-taxonomy.md](../../guidelines/entity-taxonomy.md), §7.
4. **Мета-блок** — [meta-block.md](../../guidelines/meta-block.md).


============================================================
## Пример 1. Тильда-блок

```
[FORMAT: Тильда-блок]
Любой блок кода верхнего уровня оборачивай в три тильды (~~~) с указанием
языка:
- для markdown-разметки → ~~~text
- для других языков → ~~~java, ~~~python и т.д.
Внутри этих блоков используй вложенные блоки кода исключительно с тройными
обратными кавычками (```) — они не нарушат внешнюю структуру.
Содержимое блоков не изменяй, меняй только обёртку.
```

Здесь:
- **правило оформления** — как оборачивать код;
- **content-neutral** — не меняет смысл кода, только его подачу;
- **не меняет тон** — модель не становится другой, просто оформляет иначе.


============================================================
## Пример 2. Timestamp

```
[FORMAT: Timestamp]
В начало каждого сообщения добавляй таймстамп в формате:
[YYYY-MM-DD HH:MM]
```

Здесь:
- **правило оформления** — что добавить к сообщению;
- **content-neutral** — не меняет содержание, добавляет метку;
- **обёртка** — то, что добавляется к ответу, а не то, что в нём.
