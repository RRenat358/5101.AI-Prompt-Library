# Гуманизация: руководство по использованию

Вспомогательная документация к промту `Гуманизация-текста-ИИ.txt`.
Не является частью промта.

============================================================
## Что это

Утилита для снятия явных маркеров ИИ-генерации с готового текста.
Заточена под академические тексты (рефераты, курсовые, дипломы, эссе,
статьи) — это 98% сценариев использования. Универсальна: работает
и с другими стилями.

============================================================
## Что модуль НЕ делает

### Не обходит детекторы ИИ-текста

Это принципиально нерешаемая задача, а не недоработка.

Детекторы системно повышают подозрение на академическом стиле
как таковом: научный текст обезличен, гладок, ритмически ровен —
а это и есть маркеры, которые ловят детекторы. Настройки
«это академ-текст, не придирайся» у детекторов нет.

Парадокс: чтобы текст понравился преподавателю, нужен академ-стиль;
чтобы не понравился детектору — не академ. Обойти это промтом нельзя.

Поэтому ориентир модуля — не детекторы, а нормальное человеческое
прочтение.

### Не меняет стиль и регистр

Академический текст на входе — академический на выходе. Блог — блог.
Смена стиля — не задача этого модуля. Если нужно перевести академ
в разговорный, это делает Писатель с явным вектором, а не Гуманизация.

### Не работает «под микроскопом»

Снимаются только маркеры, видимые невооружённым глазом или под лупой.
Специальный инструментальный анализ — вне зоны ответственности.

============================================================
## Что модуль делает

Убирает типичные маркеры ИИ-генерации:

- **Типографика:** длинные тире → короткие, ёлочки → обычные кавычки,
  заглавная после двоеточия, маркдаун, лишние пробелы.
- **Лексика:** канцеляриты, пустые связки, штампованные переходы,
  шаблонные зачины абзацев («В современном мире…»), избыточные
  усилители («крайне важно»).
- **Синтаксис:** идеальная симметрия предложений, однотипные начала,
  ритмическая монотонность.
- **Смысловые шаблоны:** «Вот есть X, ему Y», шаблонные риторические
  вопросы в конце разделов, итоги в каждом абзаце.

Сохраняет:

- Факты, цифры, имена, цитаты, ссылки.
- Профессиональные термины.
- Стиль, регистр, голос оригинала.
- Логическую структуру.
- Объём ±10%.

============================================================
## Как использовать

**В композите с Писателем:** `[Писатель] + [Гуманизация]`.
Писатель пишет, Гуманизация обрабатывает. Даёт стабильное качество
без ручной доводки.

**Standalone:** на любой готовый текст, включая написанный вами
вручную. Полезно для снятия случайных шаблонов или выравнивания
ритма после самостоятельной правки.

**На входе** — просто текст на переписывание. Особые требования
(«сохрани этот термин», «не трогай этот абзац», «перепиши суше») —
в сообщении.

============================================================
## Справочник маркеров

В репозитории отдельно лежит расширенный справочник маркеров
ИИ-текста (227 пунктов с примерами «как делает ИИ / как делает
человек», по категориям: лексика, синтаксис, пунктуация, логика,
эмоции, прагматика, жанр, орфография).

Это база знаний, не часть промта: смотреть при необходимости,
расширять по мере надобности. В сам промт включены только самые
заметные маркеры — видимые при обычном чтении.

============================================================
## Границы

- Работает с формой, а не с содержанием: если текст шаблонный
  по мыслям — гуманизация не спасёт.
- Не заменяет редактуру: фактические ошибки, логические дыры,
  стилистические проблемы остаются.
- Опытный эксперт (преподаватель) может распознать ИИ-генерацию
  по сути, а не по форме — это вне зоны возможностей модуля.
