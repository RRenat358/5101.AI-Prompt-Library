# Писатель: руководство по использованию

Вспомогательная документация к промту `Писатель.txt`.
Не является частью промта — это руководство для пользователя.

============================================================
## Зачем этот файл

Этот README — краткое руководство: какие параметры стоит указывать
в сообщении, чтобы получать от Писателя лучший результат.

`Писатель` — универсальная роль. Она не задаёт жёсткий стиль
по умолчанию и не пытается угадать вектор за вас. Это сделано
намеренно: универсальность означает, что контекст задаёте вы.
`Писатель` — не даёт ничего, от того что уже LLM умеет по дефолту. 
Это роль - точка входа для последующей корректировки и/или задания вектора.

============================================================
## В чём проблема

LLM без контекста пишет "средний" текст: нейтральный стиль,
усреднённый тон, размытая аудитория. Такой текст правильный,
но пресный — он ни для кого конкретно.

Указание ключевых параметров меняет результат радикально:
текст попадает в нужный регистр, аудиторию, объём. Разница между
"напиши про X" и "напиши про X для Y, в стиле Z, на N слов" —
это разница между черновиком и готовым текстом.

LLM легко подхватывает контекст из сообщения,
но если контекста нет, или он размыт, не явен,
то LLM тратит токены на угадывания, 
и может получиться не столь качественный результат, 
если контекст указать явно.

## Векторы — что стоит указывать

Параметры указываются в сообщении перед заданием. Список
не обязательный: указывайте то, что применимо к задаче.

--------------------
### Тип текста / назначение
Что это за текст и для чего он нужен.

Примеры:
- "реферат для ВУЗа"
- "пост в Телеграм для подписчиков"
- "техническое задание для разработчиков"
- "письмо клиенту с извинениями"
- "эссе для поступления"

--------------------
### Аудитория
Кто читатель, какой у него уровень, что он ожидает.

Примеры:
- "для школьников 8 класса"
- "для HR-менеджеров крупных компаний"
- "для подростков в Телеграм"
- "для экспертов в области X"
- "для пожилых людей, не знакомых с интернетом"

--------------------
### Объём
Сколько текста нужно.

Примеры:
- "2-3 страницы А4"
- "ровно 500 слов"
- "один абзац"
- "5-7 предложений на пункт"

--------------------
### Тон и стиль
Эмоциональная окраска, отношение к материалу.

Примеры:
- "деловой, без эмоций"
- "дружелюбный, но не панибратский"
- "ироничный, с самоиронией"
- "наставительный, как учитель"
- "нейтральный, справочный"

--------------------
### Формат
Структура текста.

Примеры:
- "заголовок, введение, 3 раздела, заключение"
- "маркированный список"
- "сплошной текст без подзаголовков"
- "с примерами в скобках"
- "с выводами после каждого раздела"

--------------------
### Референс
На кого ориентироваться. Самый мощный вектор: одна фраза
задаёт весь стилистический каркас.

Примеры:
- "как у Дмитрия Быкова — живая лекция"
- "как в New Yorker — длинные аналитические абзацы"
- "в духе советского научпопа — просто, с юмором"
- "как у Чехова — сдержанная ирония"

--------------------
### Голос автора / от чьего лица
Кто говорит в тексте.

Примеры:
- "от первого лица, я студент"
- "от лица эксперта с 20-летним опытом"
- "от лица новичка, который только разбирается"
- "безлично, как в инструкции"

--------------------
### Особые требования
Всё, что не попало в предыдущие категории.

Примеры:
- "избегай клише"
- "не используй списки"
- "добавь цитаты известных психологов"
- "не ссылайся на исследования без конкретных данных"

## Примеры: до и после

--------------------
### Пример 1. Академический текст

Плохо:
> "Напиши реферат про психологию малых групп."

Хорошо:
> "Напиши реферат про психологию малых групп для сдачи по
> предмету 'Социальная психология'. Аудитория — преподаватель
> ВУЗа, ожидает академический стиль с опорой на источники.
> Объём — 15-20 страниц. Формат — введение, теоретическая часть,
> практическая часть, заключение, список литературы."

--------------------
### Пример 2. Пост в соцсети

Плохо:
> "Напиши пост про психологию малых групп."

Хорошо:
> "Напиши пост в Телеграм про психологию малых групп для
> подписчиков-подростков 14-18 лет. Тон — дружелюбный, живой,
> без снобизма. Объём — 800-1000 знаков. Формат — короткие
> абзацы, эмодзи умеренно. Опирайся на примеры из жизни."

============================================================
## Что НЕ нужно указывать

- Всё, что LLM может вывести из контекста: если тема уже в задании,
  повторять не нужно.
- Очевидные вещи: "пиши по-русски", если вы пишете по-русски.
- Слишком детальные инструкции: "пиши грамотно, без ошибок" —
  это дефолт.

Правило простое: указывайте то, без чего текст получится не тем,
что вам нужно. Остальное LLM сделает по своим дефолтам, и это
нормально.

============================================================
## Связь с другими модулями

`Писатель` работает standalone. Если задача требует специфики —
можно добавить модули в композит:

- `Гуманизация` — если нужно снять явные маркеры ИИ-текста
  и/или тонко управлять стилем через G/L.
- Специализированные модули (редактор, психология, переводчик
  и т.д.) — под конкретные задачи.

`Писатель` не задаёт жёсткий стиль по умолчанию и не конкурирует
с модулями. Он — база, к которой подключается специфика.

============================================================
## Границы применимости

Писатель универсален, но не всезнающ:
- Не угадывает вектор за вас. Если вы написали "напиши текст
  про X" — он напишет разумный дефолт, но не идеальный под
  вашу задачу.
- Не заменяет специализированные модули для сложных задач,
  где нужна жёсткая регламентация (ГОСТ, ТЗ, юридический текст).
